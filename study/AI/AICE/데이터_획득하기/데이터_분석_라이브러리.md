### 파이썬에서 사용하는 대표적인 데이터 분석 라이브러리는 넘파이(Numpy)와 판다스(Pandas)이다.

**넘파이**는 수치 데이터를 다루는 데 활용하는 파이썬 라이브러리다.
데이터 분석을 할 때 n차원 행렬 자료 구조인 `np.array`를 사용하여 배열이나 행렬 계산 등을 간편하고 빠르게 실행할 수 있다.

**판다스**는 데이터 배열이나 테이블 형태의 데이터 등의 자료 구조를 처리하기 위한 라이브러리다.
판다스에서 많이 사용하는 자료 구조는 시리즈(Series)와 데이터프레임(DataFrame)이다.
시리즈는 1차원으로 구성된 데이터 배열이며, 데이터프레임은 행(Row)과 열(Column)로 구성된 2차원 데이터 테이블이다.

#### Numpy
넘파이를 사용하기 위해서는 넘파이 라이브러리를 가져와야 하는데 보통 np라고 하는 별칭으로 불러온다.

``` python
import numpy as np
```

``` python
a = np.array([1,2,3,4,5])
b = np.array(['대한민국', '포르투갈', '가나', '우루과이'])
c = np.array([1,2,'대한민국', '포르투갈'])
```

n차원 행렬 자료 구조는 ndarray를 사용한다.

#### Pandas
판다스를 사용하기 위해서는 판다스 라이브러리를 가져와야 하는데, 보통 pd라는 별칭으로 선언한다.
``` python
import pandas as pd
```

먼저 **시리즈**를 생성하는 방법은 아래와 같다.
```
변수명 = pd.Series(data, index=index, name=name)
```

``` python
# 예시
s = pd.Series(['대한민국', '포르투갈', '가나', '우루과이'], index=['가', '나', '다', '라'], name = "2022 카타르월드컵 H조")
```

**데이터프레임**은 시리즈가 여러 개 합쳐진 자료형이라고 생각하면 된다.

``` python
# 딕셔너리(Dictionary) 형으로 데이터프레임(DataFrame) 생성하기
a1 = pd.DataFrame({"a" : [1,2,3], "b" : [4,5,6], "c" : [7,8,9]})

# 리스트(List)형으로 데이터프레임(DataFrame) 생성하기
a2 = pd.DataFrame([[1,2,3], [4,5,6], [7,8,9]], ["a", "b", "c"])
```
