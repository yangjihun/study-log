title: 데이터 불러오기
---

판다스에서는 다양한 형태의 데이터를 불러오기 위해 `read_XXX` 함수를 주로 사용한다.
대표적인 예시로 `read_csv`, `read_html`, `read_json` 등이 있다.

```
변수 = pd.read_csv(filepath, encoding, ...)
```

지금부터 캐글(kaggle)의 '항공권 가격 예측 데이터(Flight Price Prediction)'의 'Clean_Dataset.csv'를 사용해보겠다.

#### 데이터 설명

| 칼럼명 | 설명 | 칼럼명 | 설명 |
|-|-|-|-|
| Airline | 항공사 이름 | Destination City | 도착 도시 |
| Flight | 항공편명 | Class | 좌석 등급 |
| Source City | 출발 도시 | Duration | 비행 시간 |
| Depature Time | 출발 시간 | Days Left | 출발까지 남은 일자 |
| Stops | 환승장 수 | Price | 항공권 가격 |
| Arrival Time | 도착시간 | | |

``` python
# 넘파이(Numpy), 판다스(Pandas) 불러오기
import pandas as pd
import numpy as np

# read_csv 함수 사용하여 데이터 불러오기
flight = pd.read_csv('./Clean_Dataset.csv', encoding = 'cp949')
```
