---
title: 데이터 저장하기
---

데이터 분석을 진행하다 보면 원래 데이터를 가공하고 해당 데이터를 저장해야 하는 경우가 생긴다.

판다스에서 데이터를 저장할 때는 `to_csv` 함수를 사용한다.

``` python
# a2 데이터프레임 만들기
a2 = pd.DataFrame([[1, 2, 3], [4, 5, 6], [7, 8, 9]], ['a', 'b', 'c'])

# to_csv 함수 활용하여 저장하기
a2.to_csv('./result_a2.csv')

# result_a2.csv 불러오기
result = pd.read_csv('./result_a2.csv', encoding='cp949')
result
```

`read_csv`함수가 가지는 다양한 파라미터를 이용하여 원하는 칼럼만 가지고 데이터프레임을 구성할 수도 있다.

``` python
# read_csv 함수의 파라미터를 활용하여 원하는 칼럼만 가지고 데이터프레임 만들기
flight2 = pd.read_csv('./Clean_Dataset.csv', index_col='stops', usecols=['stops', 'departure_time', 'arrival_time', 'destination_city'])
flight2
```

위의 예시는 인덱스를 설정할 칼럼을 정하고, 원하는 칼럼만 가지고 와서 flight2라는 데이터프레임을 구성한 것이다.

`index_col`은 인덱스로 설정할 칼럼을 정의한다. `usecols`는 실제로 데이터프레임에 불러올 칼럼들만 정의할 수 있다.
이때 주의할 점은 `usecols`는 반드시 `index_col`로 설정한 칼럼명을 포함해야 한다.

`crosstab`은 판다스 라이브러리에서 범주형 데이터 2개를 비교 분석할 때 사용한다.

``` python
# crosstab 확인하기
pd.crosstab(index=flight.source_city, columns=flight.arrival_time)
```
